# 空域平滑、锐化与边缘保持（Spatial Filtering）

## 1. 现象：更平滑，为什么反而不能用？

一块平坦灰底上的颗粒变少了，但用于定位的边缘变宽，小亮线也变淡。这不是简单的“去噪成功”：如果任务需要那根线，处理已经伤害了目标。

本篇从**噪声假设 → 结构保护目标 → 候选方法 → 副作用预测 → 受控比较 → 选择理由**出发。先问想保留什么，再调用 API。

## 2. 为什么现在学 / 当前深度

[卷积与 LSI](/knowledge/dip-convolution-lsi/)提供局部算子语言，[噪声模型](/knowledge/dip-noise-models/)提供可控输入。这里把二者用于方法选择。[Stage 2 基础滤波](/knowledge/opencv-filtering-basics/)教过正确运行 mean/Gaussian 和最小锐化；本篇不重写它，而是判断何时值得平滑、何时应该拒绝结果。锐化不能补回已经被删除的信息，本篇不再增加锐化实验。

`master` 限于独立完成小实验、预测和诊断，允许查 API。当前不学频域滤波、Wiener、逆恢复、non-local means、BM3D、深度去噪、完整质量指标或相机标定。也不需要先学尚未发布的 quality-metrics、edge-detection、enhancement。

## 3. 四种方法，四种假设与风险

### Mean / Box：把邻居等权平均

在真正平坦区域，若随机扰动大致独立、没有共同偏置，多个样本平均可让正负波动部分抵消。但阶跃旁的邻域同时含暗侧和亮侧，平均会生成中间亮度，过渡因此变宽。相关噪声或偏置不保证被同样消除。

### Gaussian：中心权重大，不是永远更高级

固定 Gaussian 核与 mean 都是线性局部加权和；Gaussian 按空间距离衰减权重。sigma 控制空间平滑尺度，kernel size 限定读取范围，二者相关但不是同一个量。核太小会截断较大 sigma 的支撑。本页明确同时记录二者，不比较含糊的“默认高斯”。

Gaussian noise 与 Gaussian filter 名称相似，不意味着 Gaussian-like noise 下 Gaussian filter 一定最佳；它只是合理候选，是否合适仍须在当前受控条件下，结合结构目标、参数尺度、评价标准和允许的细节损失验证。

### Median：排序取中间，不是卷积

**中值（median）**将邻域数值排序后取中间项。九个值中八个为 0.2、一个为 1，mean 被拉高，中值仍为 0.2。少量极端异常值不容易越过中间排序位置，因此盐椒条件下常有用。

这是一种**非线性局部操作**，不是固定核加权和，不能套用 LSI。若一根真实细线在邻域里也占少数，中值一样可能把它当成背景替换；密集污染也会改变中间项。不能推断“对脉冲有效，所以所有噪声都最好”。

### Bilateral：空间接近，还要强度相似

**双边滤波（bilateral）**同时考虑邻居距离和它与中心像素的强度差。跨强边缘的像素虽然距离近，却可能因差值大获得很小权重；这是边缘保持的工程直觉，不是完整保护保证。权重依赖当前图像，因此它也不是固定的线性卷积。

`sigmaSpace` 以像素为尺度；`sigmaColor` 是当前强度单位下的差值尺度，在本页 0–1 数据上不能照搬 0–255 图片的参数。range 尺度太小会拒绝噪声扰动的邻居；太大则弱化强度筛选、接近空间平滑。异常脉冲也可能因与邻居差异大而被保留下来。

## 4. 公平比较与最小检查

公平不是所有参数写成同一个数字，而是输入、任务、统计区域、显示和选择规则透明。这里固定 clean 与每种 noisy；所有方法读取同一份 noisy，不为每种方法重新抽噪声，也不串联运行。

只使用本篇够用的三个检查：

- **MSE（均方误差）**：`mean((result-clean)**2)`，先在 float 中作差。它描述当前 reference 的平均平方差，越小越接近此 clean，不等于所有任务质量越好。
- **平坦区 residual std**：只在没有真实结构且远离外边界的区域计算，避免把场景变化算成噪声。
- **阶跃 profile（剖面）**：对同一行带沿列画亮度，比较过渡形状，并记录已知边缘两侧相邻列差；它不是通用边缘检测器。另检查已知细线的对比度。

真实图片通常没有 clean 真值；本页证据只验证合成条件下的取舍，不直接证明工业效果。

## 5. Worked Example：同一结构，两种噪声

复用现有环境，以下四个 checkpoint 顺序运行。输入有左右两块平坦区、x=64 阶跃和左侧三像素宽亮线，无需下载图片。

### Checkpoint 1：固定输入与方法契约

先预测：连续噪声下平滑可能降低平坦区 std，但跨阶跃会混合；脉冲条件下 median 可能有利，bilateral 可能误保留异常值。不要预先选一个全局冠军。

```python
import cv2
import numpy as np
import matplotlib.pyplot as plt

clean = np.full((96, 128), 0.2, dtype=np.float32)
clean[:, 64:] = 0.8
clean[16:80, 24:27] = 0.9
original = clean.copy()
seed = 83
noise = np.random.default_rng(seed).normal(0, 0.06, clean.shape).astype(np.float32)
gaussian_input = clean + noise  # 不先 clip，以免改变模型
draws = np.random.default_rng(seed + 1).random(clean.shape)
impulse_input = clean.copy()
impulse_input[draws < 0.025] = 0
impulse_input[(draws >= 0.025) & (draws < 0.05)] = 1
BORDER = cv2.BORDER_REPLICATE

def candidates(source):
    assert source.ndim == 2 and source.dtype == np.float32
    assert np.isfinite(source).all()
    snapshot = source.copy()
    outputs = {
        "raw": source.copy(),
        "mean5": cv2.blur(source, (5, 5), borderType=BORDER),
        "gauss5": cv2.GaussianBlur(source, (5, 5), 1.0,
                                  sigmaY=1.0, borderType=BORDER),
        "median3": cv2.medianBlur(source, 3),
        "bilateral": cv2.bilateralFilter(source, 9, 0.12, 2.0,
                                         borderType=BORDER),
    }
    assert np.array_equal(source, snapshot)
    for result in outputs.values():
        assert result.shape == source.shape and result.dtype == np.float32
        assert np.isfinite(result).all()
    return outputs

print("OpenCV / NumPy / seed:", cv2.__version__, np.__version__, seed)
results = {"Gaussian": candidates(gaussian_input),
           "Impulse": candidates(impulse_input)}
```

当前接口边界：`blur` 是归一化 box；若改用 `boxFilter`，需 `normalize=True`。Gaussian 本页只用正奇数 ksize 和明确 sigma。`medianBlur` 在本页 float32 路径仅用 3 或 5，不能直接改成 7；它内部固定复制边界，没有 `borderType` 参数。其他方法显式采用同一 `BORDER_REPLICATE`。Bilateral 的 `d=9` 限定邻域直径，另外两项是强度与空间尺度；本页不就地覆盖 source。所有统计在 clip 前完成。

### Checkpoint 2：数值加结构，不只看截图

先选目标：平坦区要降波动，但 x=64 阶跃与三像素线不能被不加解释地抹去。`[16:80,36:52]` 避开亮线、阶跃和最大核的边界；profile 用 `[32:64,56:72]` 行带平均，仅是降随机波动的观察辅助。

下面 `line_contrast` 是输出中已知亮线区域的均值减去固定的 clean 合成背景 `0.2`，不是从滤波后的输出重新估计邻域背景。它只是在当前确定性合成实验中检查已知细线是否被压低的简单结构读数，不是通用对比度、图像质量、边缘或工业检测指标。

```python
def checks(result):
    residual = result.astype(np.float64) - clean
    profile = result[32:64, 56:72].mean(axis=0)
    mse = np.mean(residual ** 2)
    flat_std = residual[16:80, 36:52].std(ddof=0)
    edge_jump = profile[8] - profile[7]  # 原图列 64 - 63
    line_contrast = result[32:64, 24:27].mean() - 0.2
    return mse, flat_std, edge_jump, line_contrast

for condition, outputs in results.items():
    for name, result in outputs.items():
        print(condition, name, "MSE / flat std / edge jump / line contrast:",
              np.round(checks(result), 6))
assert checks(results["Gaussian"]["mean5"])[1] < checks(gaussian_input)[1]
assert checks(results["Gaussian"]["mean5"])[2] < checks(gaussian_input)[2]
assert checks(results["Impulse"]["median3"])[0] < checks(results["Impulse"]["mean5"])[0]
assert np.array_equal(clean, original)
```

核验环境 OpenCV 5.0.0 / NumPy 2.4.6 的近似结果（不要求跨版本末位完全相同）：

| 输入 / 方法 | MSE | flat std | edge jump | line contrast |
| --- | ---: | ---: | ---: | ---: |
| Gaussian / raw | 0.003534 | 0.060015 | 0.612970 | 0.696295 |
| Gaussian / mean5 | 0.003576 | 0.011563 | 0.122999 | 0.420560 |
| Gaussian / gauss5 | 0.001821 | 0.017034 | 0.238570 | 0.534129 |
| Gaussian / median3 | 0.000771 | 0.023611 | 0.512053 | 0.677438 |
| Gaussian / bilateral | 0.000294 | 0.017003 | 0.601667 | 0.697919 |
| Impulse / raw | 0.017107 | 0.136216 | 0.575000 | 0.683333 |
| Impulse / mean5 | 0.004429 | 0.025989 | 0.117500 | 0.418667 |
| Impulse / gauss5 | 0.003262 | 0.037854 | 0.210182 | 0.528104 |
| Impulse / median3 | 0.000218 | 0.000000 | 0.581250 | 0.700000 |
| Impulse / bilateral | 0.015830 | 0.133176 | 0.583151 | 0.687176 |

连续噪声的 mean5 虽然 flat std 大幅下降，全图 MSE 却略升，因为结构损失也进入误差。当前 bilateral 较好地保留强阶跃，但脉冲条件下留下大量异常值；median3 在该样本更合适。`flat std=0` 只说明这个平坦 ROI 恢复为常量，不代表全图无误差。clean 的理想 edge jump=0.6、line contrast=0.7；数值不是越大越好，过冲也会增大它们。

### Checkpoint 3：参数代价与明确失败

预测后再运行：空间平滑尺度增大，flat std 可能下降，阶跃和亮线也可能被混合；bilateral 的 range 参数过小不能有效聚合邻居，过大则失去强度筛选。下面 Gaussian 成对修改 ksize/sigma 是“尺度方案”比较，不把变化只归因于 sigma；bilateral 只改变 sigmaColor。

```python
for k, sigma in [(3, 0.6), (5, 1.0), (9, 2.0)]:
    output = cv2.GaussianBlur(gaussian_input, (k, k), sigma,
                              sigmaY=sigma, borderType=BORDER)
    print("Gaussian scale", k, sigma, checks(output))
for range_sigma in (0.005, 0.12, 2.0):
    output = cv2.bilateralFilter(gaussian_input, 9, range_sigma, 2.0,
                                 borderType=BORDER)
    print("bilateral range", range_sigma, checks(output))

# 单独改变结构宽度的失败探针，不与前表混作同一输入排名。
thin = np.full((21, 21), 0.2, dtype=np.float32)
thin[:, 10] = 0.9
thin_snapshot = thin.copy()
lost = cv2.medianBlur(thin, 5)
assert np.isclose(thin[10, 10], 0.9)
assert np.isclose(lost[10, 10], 0.2)
assert np.array_equal(thin, thin_snapshot)
print("input: one-pixel line, median5; expected: preserve 0.9 line")
print("actual:", lost[10, 10], "reason: line is minority in 5x5 neighborhood")
print("correction: reconsider method/structure scale; do not label real detail as noise")
```

当前 Gaussian 三方案 flat std 约 0.0300 → 0.0170 → 0.0083，edge jump 约 0.401 → 0.239 → 0.122。Bilateral range 从 0.005 到 2.0，分别暴露“近乎保留原噪声”与“混合边缘”的两端。细线失败中 5×5 邻域只有 5 个线像素、20 个背景像素，中间排序值为背景；甚至 3×3 也不能保证保护一像素线。修正不是承诺“缩核必能救回”，而是回到结构目标选择方法。

### Checkpoint 4：统一显示与 profile

`subplots` 创建多个绘图区，`plot(x,y)` 按列坐标连接剖面值；不是提取未知边缘。所有图使用同一灰度范围，显示裁剪不回写 raw；剖面也保持同一坐标范围。

```python
for condition, outputs in results.items():
    fig, axes = plt.subplots(2, 5, figsize=(14, 5))
    for col, (name, result) in enumerate(outputs.items()):
        axes[0, col].imshow(np.clip(result, 0, 1), cmap="gray",
                            vmin=0, vmax=1, interpolation="nearest")
        axes[0, col].set_title(condition + " / " + name)
        axes[1, col].plot(np.arange(56, 72), clean[32:64, 56:72].mean(axis=0), label="clean")
        axes[1, col].plot(np.arange(56, 72), result[32:64, 56:72].mean(axis=0), label="result")
        axes[1, col].set_xlim(56, 71)
        axes[1, col].set_ylim(0, 1)
        axes[1, col].set_xlabel("column / pixel")
        axes[1, col].set_ylabel("mean intensity")
        axes[1, col].legend()
    plt.tight_layout()
plt.show()
assert np.array_equal(clean, original)
```

选择记录应写“在本次连续噪声、强阶跃和指定参数下，我选择/拒绝……，依据是……，仍未验证纹理、低对比度或真实噪声”，而不是“这个滤波器最好”。两种噪声不要求产生同一个 winner。

## 6. Active Recall

- 为什么 mean 降低平坦区波动时，也会在阶跃两侧产生中间值？
- flat std 下降但细线消失，你还需要什么证据才能接受结果？
- median 为什么可能去掉盐椒，也可能去掉真实亮线？为什么它不是卷积？
- bilateral range 过大或过小分别会怎样？从 0–255 改成 0–1 后为何不能照抄 range 参数？
- 相同 kernel size 为什么不等于相同作用或公平比较？
- 全图 MSE 降低、profile 却变宽时，为什么不能仅凭一个数字下结论？

## 7. Practice：复用同一短记录

1. **连续噪声选择**：固定正文 Gaussian 输入，至少比较两种方法；写下预测、参数、MSE、flat std、profile 与线对比，依据保边目标选择或拒绝。完成标准是可核查的理由，不规定必须选哪种方法。
2. **脉冲假设**：将替换概率改为 0.08（黑白各半）；运行前先预测污染密度提高后 median 的优势可能如何变化、它是否也可能失效、结构损失风险是否可能增加。再固定新输入，运行 median 与至少一种线性方法，记录实际替换比例、误差和结构，解释预测是否成立；即便结果出乎预期，也先检查输入与参数，不篡改统计。
3. **单参数对照**：固定 bilateral 的 d=9、sigmaSpace=2，只改 sigmaColor=0.005/0.12/2；先预测，再解释两端失败及中间方案。不要求 grid search。
4. **结构失败**：复现一像素线失败，并把线宽改成三像素比较同一个 median5；运行前先预测目标像素在邻域中的占比如何变化、何时更可能保留细线，以及为什么不能只按 kernel 大小判断。再运行，检查中心值、source 相等与五项失败卡，对比预测并解释结构占比的作用，不把它称为参数魔法。

## 8. Mastery Evidence

两项 required，可以放在一份短记录中：

1. **Controlled filtering comparison**：固定一个噪声输入，对至少两种方法保存 noise condition、seed/版本、参数、数值结果与结构结果；说明选择或拒绝理由与适用边界，不只贴“更干净”的图。
2. **Tradeoff / failure diagnosis**：改变一个关键参数或结构，提交前后预测与检查、source 断言，以及 input / expected / actual / reason / correction。解释平滑与细节的代价，不以 MSE 一项替代任务判断。
