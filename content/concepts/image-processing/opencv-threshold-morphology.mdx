# 阈值与形态学（Thresholding & Morphology）

本页只解决一个工程问题：**怎样从已经验证的灰度图得到可信的区域 mask，再在明确假设下修改它的局部结构，并证明真正目标没有被误删。**

```text
validated grayscale image
→ inspect dtype / range
→ choose threshold rule
→ produce binary mask
→ inspect shape / dtype / values / foreground polarity
→ choose structuring element
→ apply controlled morphology
→ compare structure before / after
→ verify desired target retained
→ diagnose failures
```

## 1. 这是什么

**阈值（thresholding）**按像素值条件把每个位置分类为 foreground（前景）或 background（背景）。本页主线把白色 `255` 定义为 foreground，把黑色 `0` 定义为 background。

**形态学（morphology）**不再比较原灰度值，而是在 binary foreground 上使用 **structuring element（结构元素）**检查局部结构关系。它会改变区域形状，因此不能因为结果“更干净”就自动认为更正确。

三类操作回答不同问题：

| 操作 | 当前问题 | 主要数据 |
| --- | --- | --- |
| Filtering | 邻域怎样重新计算连续像素值？ | 灰度或彩色像素值 |
| Thresholding | 哪些像素满足 foreground 条件？ | 单通道数值 → binary mask |
| Morphology | binary foreground 的局部结构怎样改变？ | binary mask + structuring element |

## 2. 为什么机器视觉需要它

### 为什么现在学

`opencv.io-color` 已经让你能可靠获得 grayscale 数组，`opencv.roi-masks` 已经建立 H×W mask 与 source protection。本页把两者连接为第一次可验证的区域提取：不仅会调用 API，还能说明 mask 为什么是这个 shape、这些值，以及参数是否破坏了目标。

`opencv.filtering-basics` 可能在某些任务中作为 threshold 前的可选降噪步骤，但不是本页 hard prerequisite。主实验不依赖 blur；若以后加入 preprocessing，必须重新检查处理后的 dtype、range 和阈值单位。

## 4. 核心概念

### 4.1 固定阈值：先声明比较规则

本页主线使用 `THRESH_BINARY`：

```text
pixel > T  → maxval
pixel <= T → 0
```

注意严格大于号：像素恰好等于 `T` 时输出 0。

```python
ret, mask_u8 = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
```

- `T=127` 是本次比较阈值；
- `maxval=255` 是满足条件时的输出值；
- `ret` 是实际使用的 threshold，固定阈值实验中为 `127.0`；
- `mask_u8` 才是 binary output。

`THRESH_BINARY_INV` 只反转当前比较方向：较暗值变成白色 foreground。它用于解释 dark target 与 foreground polarity，不扩展其他 threshold type。

### 4.2 Grayscale、range 与 threshold 必须使用同一契约

threshold 前至少检查：

```python
assert gray.ndim == 2
print("shape:", gray.shape)
print("dtype:", gray.dtype)
print("actual range:", gray.min().item(), gray.max().item())
```

`T=127` 对 `uint8` 0–255 灰度可能合理，对 float32 0–1 数据则完全不在同一尺度。代码不报错也不表示比较条件有意义。

OpenCV 在当前宿主上也能对 H×W×3 BGR 数组逐通道 threshold，得到 H×W×3 输出；这不是本页要求的 H×W spatial mask。因此 **API 成功不等于数据契约正确**。

### 4.3 Boolean mask 与 OpenCV 0/255 binary image

```text
NumPy boolean mask          OpenCV binary image
shape: H×W                 shape: H×W
dtype: bool                dtype: uint8
values: False / True       values: 0 / 255
```

正式转换：

```python
mask_u8 = mask_bool.astype(np.uint8) * 255

values = set(np.unique(mask_u8).tolist())
assert values.issubset({0, 255})
mask_bool_again = mask_u8 > 0
```

必须先检查 binary values，再使用 `>0`。任意普通 `uint8` 灰度图也可以含非零值；直接 `>0` 会把它们全部选为 True。

### 4.4 Structuring element 不是 averaging kernel

主路径使用：

```python
kernel_3 = np.ones((3, 3), dtype=np.uint8)
```

- shape 是 3×3；
- 非零位置定义参与结构判断的邻域；
- 当前使用默认中心 anchor；
- `iterations=1` 表示应用一次。

Filtering kernel 通常把邻域数值乘权重后相加；morphology structuring element 主要决定哪些邻域位置参与 min/max 式结构判断。这里的九个 1 **不是** mean filter 的九个 `1/9`。

`cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))` 是选看等价接口。本页不比较 ellipse 或 cross。

### 4.5 Erosion 与 dilation

在当前白色 `255` foreground 契约下：

- **erosion（腐蚀）**：只有 structuring element 覆盖的局部邻域都支持 foreground 时，中心 foreground 才保留，因此前景通常缩小；
- **dilation（膨胀）**：局部邻域存在 foreground 时，输出位置更容易成为 foreground，因此前景通常扩大。

这些是条件化结论。实际效果还依赖 foreground polarity、structuring element、iterations、border，以及目标是否接触图像边缘。

### 4.6 Opening 与 closing

- **opening（开运算）** = erosion → dilation。对当前白色 foreground，它常用于删除比 structuring element 更小的孤立 foreground，再尝试恢复剩余主体的大致尺寸；
- **closing（闭运算）** = dilation → erosion。它常用于填补比 structuring element 更小的背景缺口或狭窄断裂。

它们都不是万能清理。每次使用后仍要检查 desired target coverage、已知像素和 foreground count。

### 4.7 Border 是任务假设

主实验显式使用：

```python
borderType=cv2.BORDER_CONSTANT,
borderValue=0,
```

这里主动假设图像外是 background，并把目标放在距离边界至少一个像素的位置。OpenCV morphology 的默认 constant border 使用专用中性值，并不等价于“默认外部全是 0”；所以不能把隐藏默认值当作无意义细节。

`iterations=2` 表示同一个 operation 连续应用两次，不是 “kernel size=2”。本页主线始终固定 `iterations=1`。

## 5. 初学者直觉解释

threshold 像先给每个格子发一张“前景/背景”标签；morphology 像拿一个小模板在标签图上逐格检查邻居。模板越大，要求或影响的局部范围越大，因此既可能清掉小噪点，也可能把真正目标一起删掉。

所以正式问题不是“结果更白还是更黑”，而是：

1. foreground 代表谁？
2. 哪些像素因为什么规则改变？
3. desired target 是否仍满足已知位置和面积检查？

## 6. 必须掌握到什么程度

- 能独立完成 fixed `THRESH_BINARY`，解释 `ret`、严格比较方向和 polarity；
- 能验证 H×W、uint8、0/255 binary contract，并与 bool mask 安全往返；
- 能手算并验证 3×3 erosion 与 dilation；
- 能用最小 opening/closing 处理受控噪点和小缺口；
- 能用 count、target ROI 与 known pixels 判断 cleanup 是否保留目标；
- 能诊断照明、range、BGR、bool、kernel size、border 和 display failure。

当前不学习 adaptive threshold、Otsu、灰度形态学、connected components、contours、Canny、完整 segmentation 或 morphology 集合论证明。

## 7. 常见误区

- 用 `_` 隐藏 `ret`，却不知道 threshold 实际用了什么值；
- 忘记 `pixel == T` 在 `THRESH_BINARY` 下输出 0；
- 对 BGR 三通道数组 threshold，看到代码成功就当作 H×W mask；
- 对 0–1 float 使用 `T=127`；
- 看到 `uint8` 就断定 values 一定是 0/255；
- 把 bool mask 直接交给 OpenCV morphology；
- 把 3×3 ones structuring element 当成 averaging kernel；
- threshold 后固定套 morphology，不检查目标是否被删；
- 只看 auto-scaled 显示，不检查 unique values 与 foreground count；
- 忽略 border 假设，或把 iterations 和 kernel size 当成同一个参数。

## 8. Worked Example

下面四个 checkpoint 可逐段运行。所有数值来自同一个固定 synthetic fixture，不需要下载数据集。

### Checkpoint 1 — Threshold contract 与三种 illumination

```python
import cv2
import matplotlib.pyplot as plt
import numpy as np


def make_threshold_fixture():
    image = np.full((9, 13), 30, dtype=np.uint8)
    image[2:7, 3:10] = 180       # 5×7 bright target
    image[4, 6] = 30             # one background hole inside target
    image[1:3, 10:12] = 90       # darker distractor
    image[1, 1] = 220            # isolated bright noise
    image[7, 11] = 220           # isolated bright noise
    return image


def inspect_binary(label, mask, expected_shape):
    values = set(np.unique(mask).tolist())
    foreground_count = int(np.count_nonzero(mask))
    print(label)
    print("  shape:", mask.shape)
    print("  dtype:", mask.dtype)
    print("  unique:", sorted(values))
    print("  foreground:", foreground_count)
    assert mask.shape == expected_shape
    assert mask.dtype == np.uint8
    assert values.issubset({0, 255})
    return foreground_count


small_gray = np.array(
    [
        [30, 90, 127, 128, 180],
        [220, 30, 90, 180, 255],
    ],
    dtype=np.uint8,
)
expected_small = np.array(
    [
        [0, 0, 0, 255, 255],
        [255, 0, 0, 255, 255],
    ],
    dtype=np.uint8,
)

ret, small_mask = cv2.threshold(
    small_gray,
    127,
    255,
    cv2.THRESH_BINARY,
)
assert ret == 127.0
assert np.array_equal(small_mask, expected_small)
assert small_mask[0, 2] == 0  # pixel == T

ret_inv, small_mask_inv = cv2.threshold(
    small_gray,
    127,
    255,
    cv2.THRESH_BINARY_INV,
)
assert ret_inv == 127.0
assert np.array_equal(small_mask_inv, 255 - expected_small)

source = make_threshold_fixture()
original = source.copy()
assert source.shape == (9, 13)
assert source.dtype == np.uint8
assert (source.min().item(), source.max().item()) == (30, 220)
assert source[2, 3] == 180
assert source[4, 6] == 30
assert source[1, 1] == source[7, 11] == 220

ret, raw_mask = cv2.threshold(source, 127, 255, cv2.THRESH_BINARY)
assert ret == 127.0
assert inspect_binary("nominal", raw_mask, source.shape) == 36
assert np.count_nonzero(raw_mask[2:7, 3:10]) == 34

raw_bool = raw_mask > 0
raw_u8_again = raw_bool.astype(np.uint8) * 255
assert raw_bool.dtype == np.bool_
assert np.array_equal(raw_u8_again, raw_mask)


def shift_intensity_safely(image, delta):
    working = image.astype(np.int16) + delta
    return np.clip(working, 0, 255).astype(np.uint8)


illumination_results = {}
for label, delta in [("dark", -70), ("nominal", 0), ("bright", 110)]:
    shifted = shift_intensity_safely(source, delta)
    used_threshold, shifted_mask = cv2.threshold(
        shifted,
        127,
        255,
        cv2.THRESH_BINARY,
    )
    illumination_results[label] = {
        "ret": used_threshold,
        "foreground": int(np.count_nonzero(shifted_mask)),
        "target": int(np.count_nonzero(shifted_mask[2:7, 3:10])),
    }

assert illumination_results == {
    "dark": {"ret": 127.0, "foreground": 2, "target": 0},
    "nominal": {"ret": 127.0, "foreground": 36, "target": 34},
    "bright": {"ret": 127.0, "foreground": 117, "target": 35},
}

too_low = cv2.threshold(source, 20, 255, cv2.THRESH_BINARY)[1]
too_high = cv2.threshold(source, 200, 255, cv2.THRESH_BINARY)[1]
assert np.count_nonzero(too_low) == 117
assert np.count_nonzero(too_high) == 2
assert np.array_equal(source, original)
```

预期：同一 `T=127` 在 dark 条件下丢失整个 target，在 nominal 条件下保留 34/35 个 target pixels，在 bright 条件下把全部 117 个位置都判为 foreground。这是 fixed threshold 的边界，不是引入 Otsu 或 adaptive threshold 的理由。

### Checkpoint 2 — Erosion / Dilation 手算与 bool 边界

```python
kernel_3 = np.ones((3, 3), dtype=np.uint8)
assert np.array_equal(
    kernel_3,
    cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3)),
)

erosion_input = np.zeros((5, 5), dtype=np.uint8)
erosion_input[1:4, 1:4] = 255
erosion_original = erosion_input.copy()
eroded = cv2.erode(
    erosion_input,
    kernel_3,
    iterations=1,
    borderType=cv2.BORDER_CONSTANT,
    borderValue=0,
)
assert eroded.shape == erosion_input.shape
assert eroded.dtype == np.uint8
assert set(np.unique(eroded).tolist()) == {0, 255}
assert np.count_nonzero(eroded) == 1
assert eroded[2, 2] == 255
assert eroded[1, 1] == 0
assert np.array_equal(erosion_input, erosion_original)

dilation_input = np.zeros((5, 5), dtype=np.uint8)
dilation_input[2, 2] = 255
dilation_original = dilation_input.copy()
dilated = cv2.dilate(
    dilation_input,
    kernel_3,
    iterations=1,
    borderType=cv2.BORDER_CONSTANT,
    borderValue=0,
)
assert dilated.shape == dilation_input.shape
assert dilated.dtype == np.uint8
assert set(np.unique(dilated).tolist()) == {0, 255}
assert np.count_nonzero(dilated) == 9
assert np.all(dilated[1:4, 1:4] == 255)
assert dilated[0, 0] == 0
assert np.array_equal(dilation_input, dilation_original)

bool_rejected = False
try:
    cv2.erode(erosion_input > 0, kernel_3)
except cv2.error:
    bool_rejected = True

assert bool_rejected
```

预测与实测一致：3×3 foreground block 被 erosion 留下一个中心点；单个 foreground point 被 dilation 扩为 3×3 block。这里验证的是结构关系，不是加权平均。

### Checkpoint 3 — Opening / Closing cleanup 与过激参数

```python
opened = cv2.morphologyEx(
    raw_mask,
    cv2.MORPH_OPEN,
    kernel_3,
    iterations=1,
    borderType=cv2.BORDER_CONSTANT,
    borderValue=0,
)
cleaned = cv2.morphologyEx(
    opened,
    cv2.MORPH_CLOSE,
    kernel_3,
    iterations=1,
    borderType=cv2.BORDER_CONSTANT,
    borderValue=0,
)

assert inspect_binary("raw", raw_mask, source.shape) == 36
assert inspect_binary("opened", opened, source.shape) == 30
assert inspect_binary("cleaned", cleaned, source.shape) == 35

assert [
    np.count_nonzero(mask[2:7, 3:10])
    for mask in (raw_mask, opened, cleaned)
] == [34, 30, 35]

assert raw_mask[1, 1] == raw_mask[7, 11] == 255
assert opened[1, 1] == opened[7, 11] == 0
assert cleaned[1, 1] == cleaned[7, 11] == 0
assert raw_mask[4, 6] == opened[4, 6] == 0
assert cleaned[4, 6] == 255

kernel_5 = np.ones((5, 5), dtype=np.uint8)
aggressive_open = cv2.morphologyEx(
    raw_mask,
    cv2.MORPH_OPEN,
    kernel_5,
    iterations=1,
    borderType=cv2.BORDER_CONSTANT,
    borderValue=0,
)
assert np.count_nonzero(aggressive_open) == 0
assert np.count_nonzero(aggressive_open[2:7, 3:10]) == 0
assert np.array_equal(source, original)

figure, axes = plt.subplots(1, 4, figsize=(11, 3))
for axis, image, title in zip(
    axes,
    [source, raw_mask, opened, cleaned],
    ["grayscale source", "raw threshold", "3×3 opening", "then 3×3 closing"],
):
    axis.imshow(image, cmap="gray", vmin=0, vmax=255)
    axis.set_title(title)
    axis.axis("off")
plt.tight_layout()
plt.show()
```

opening 删除了两个孤立 noise pixels，但也暂时损失了 target 中的四个 foreground pixels；closing 随后填回小缺口，使 target ROI 达到 35。计数变化本身不是“更好”的证明，已知 target/noise/hole 检查才说明当前变化是否符合任务。

5×5 opening 把 foreground 降为 0：输入目标相对 structuring element 太小，主体被完全删除。修正应是减小 kernel，或重新判断 morphology 是否适合，而不是继续增加 iterations。

### Checkpoint 4 — Border 与统一 failure diagnosis

```python
def report_diagnosis(name, input_fact, expected, actual, reason, correction):
    print(f"[{name}]")
    print("input:", input_fact)
    print("expected:", expected)
    print("actual:", actual)
    print("reason:", reason)
    print("correction:", correction)


full_foreground = np.full((3, 3), 255, dtype=np.uint8)
erode_default = cv2.erode(full_foreground, kernel_3)
erode_outside_background = cv2.erode(
    full_foreground,
    kernel_3,
    borderType=cv2.BORDER_CONSTANT,
    borderValue=0,
)
assert np.count_nonzero(erode_default) == 9
assert np.count_nonzero(erode_outside_background) == 1

corner_point = np.zeros((3, 3), dtype=np.uint8)
corner_point[0, 0] = 255
dilate_default = cv2.dilate(corner_point, kernel_3)
dilate_outside_foreground = cv2.dilate(
    corner_point,
    kernel_3,
    borderType=cv2.BORDER_CONSTANT,
    borderValue=255,
)
assert np.count_nonzero(dilate_default) == 4
assert np.count_nonzero(dilate_outside_foreground) == 9

bgr_probe = np.array([[[10, 200, 30], [250, 20, 220]]], dtype=np.uint8)
_, bgr_threshold = cv2.threshold(
    bgr_probe,
    127,
    255,
    cv2.THRESH_BINARY,
)
report_diagnosis(
    "BGR threshold contract",
    {"input shape": bgr_probe.shape, "dtype": bgr_probe.dtype},
    "H×W single-channel binary mask",
    {"output shape": bgr_threshold.shape, "unique": np.unique(bgr_threshold)},
    "OpenCV 对三个通道分别比较，API 成功但输出不是 spatial mask contract。",
    "先明确转换或读取 grayscale，再 threshold。",
)

float_probe = np.array([[0.1, 0.4, 0.9]], dtype=np.float32)
_, wrong_scale_mask = cv2.threshold(
    float_probe,
    127,
    255,
    cv2.THRESH_BINARY,
)
assert np.count_nonzero(wrong_scale_mask) == 0
report_diagnosis(
    "threshold / range mismatch",
    {"dtype": float_probe.dtype, "range": (0.1, 0.9), "T": 127},
    "threshold 与输入使用同一数值尺度",
    {"foreground": 0, "output dtype": wrong_scale_mask.dtype},
    "0–1 数据中的所有值都小于 127，代码运行但比较无意义。",
    "改用同尺度 threshold，例如 T=0.5，并按任务选择 maxval。",
)

report_diagnosis(
    "aggressive morphology",
    {"target ROI": (5, 7), "kernel": (5, 5), "iterations": 1},
    "删除孤立噪点并保留 target 主体",
    {"foreground": np.count_nonzero(aggressive_open), "target": 0},
    "structuring element 相对目标结构过大。",
    "减小 kernel，或重新评估 morphology 是否适合。",
)
```

wrong polarity、bool input、threshold too low/high 也按同一五字段格式记录。显示 mask 时固定 `cmap="gray", vmin=0, vmax=255`；auto scaling 可能让错误范围仍显得黑白分明，不能替代 dtype、unique values 与 count。
