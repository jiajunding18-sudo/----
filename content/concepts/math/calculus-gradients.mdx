# 微积分、偏导、链式法则与梯度（Calculus and Gradients）

本单元只学习视觉算法反复使用的变化率、链式法则和梯度检查。重点是“能解释、能手推、能数值验证”，不是覆盖完整微积分课程。

## 1. 这是什么

**导数（derivative）**描述函数输出对输入的局部变化率。多变量函数对一个变量的变化率叫**偏导数（partial derivative）**；把所有偏导按参数顺序组成向量，得到**梯度（gradient）**。

先看一个不用正式符号的差商。沿图像一行观察灰度，位置 9 的灰度是 38，位置 11 的灰度是 46，那么位置 10 附近的平均变化率可以估为

$$
\frac{46-38}{11-9}=4\quad\text{灰度级/像素}.
$$

它表示“向右移动 1 个像素，灰度在这里大约增加 4”，而不是说整行图像都按这个速度变化。把两次取样的位置逐渐靠近当前点，就得到导数的局部思想；现在再用 $f'(x)$ 表示函数 $f$ 在位置 $x$ 的导数。

若输出通过多层函数得到，**链式法则（chain rule）**把各层局部变化率相乘。**有限差分（finite difference）**用函数值近似导数，可作为检查手推或程序实现的独立方法。

## 2. 为什么机器视觉需要它

### 为什么现在学

图像边缘是亮度随位置快速变化的地方，参数优化需要知道损失随参数怎样变化，训练则依赖梯度传播。现在先用简单标量和二维坐标建立检查方法，后续遇到卷积、光流或自动微分时才不会把梯度当作黑箱数字。

### 在机器视觉中会在哪里使用

- 灰度剖面的空间导数和边缘检测；
- 光流中的亮度变化与空间梯度；
- 标定、配准和重建中的损失最小化；
- 深度学习的自动微分、反向传播和参数更新。

## 3. 前置知识

硬前置是 `tooling.python-core`。推荐先学 `math.vectors-matrices`，以便把多个偏导按明确形状组织成梯度。开始前只需会基本代数、函数和平方展开；遇到缺失的高中函数知识时按例子局部补齐，不扩张成整门预备课程。

## 4. 核心概念

- **局部变化率**：$f'(x)$ 说明在 $x$ 附近，输入增加一点时输出大约改变多少。
- **切线近似**：$f(x+h)\approx f(x)+f'(x)h$，只在足够小的局部可信。
- **偏导与梯度**：对 $L(x,y)$，梯度是 $[\partial L/\partial x,\partial L/\partial y]^T$，方向约定必须和参数排列一致。
- **链式法则**：若 $L(g)=q(g)^2$，则 $dL/dg=2q\,dq/dg$。漏掉内层导数是常见错误。
- **梯度方向**：梯度指向局部增长最快方向，负梯度是局部下降方向；这不保证任意步长都能得到更好结果。
- **有限差分检查**：中心差分 $[f(x+h)-f(x-h)]/(2h)$ 通常比单边差分更准确。$h$ 太大有截断误差，太小会受浮点舍入影响。

### 视觉里两种常见的“梯度”

- **图像空间梯度** $\nabla I(x,y)$：变量是空间坐标 $x,y$，对象是图像亮度函数 $I$。它描述亮度随图像位置怎样变化，后续用于边缘和光流等问题。
- **参数梯度** $\nabla_{\theta}L$：变量是模型或优化参数 $\theta$，对象是损失函数 $L$。它描述参数改变时损失怎样变化，后续用于配准、优化和模型训练。

它们使用同一种导数/梯度数学语言，但不是同一个具体对象。看到 $\nabla$ 时必须先问“对哪些变量求导、被求导的函数是什么”。本页 Worked Example 的 $dL/dg$ 是参数梯度的一维版本；视觉小练习中的灰度差分是在估计图像空间梯度。

## 5. 初学者直觉解释

把损失曲线想成山坡。导数是脚下坡度，不是整座山的地图；梯度是多维地形中最陡的上坡箭头。有限差分则是在脚前后各量一次高度，用两次测量估计坡度。若手推箭头和数值测量方向相反，先查公式或实现，不要直接调学习率。

## 6. 必须掌握到什么程度

- **知道是什么**：能说明导数、偏导、梯度和链式法则的用途。
- **理解**：能解释梯度的方向、参数顺序和有限差分的近似性质。
- **应用**：能对平方误差等简单损失手推梯度，并用代码做多步长数值检查。
- **达到本页 `master` 目标**：必须通过一项独立推导和一项包含故意错误诊断的梯度检查证据。

当前不要求严格的极限证明，不要求完整积分技巧，不要求 Hessian、复杂约束优化或神经网络反向传播推导。优化算法将在 Stage 1B，自动微分与训练将在 Stage 7A。

## 7. 常见误区

- 只背求导公式，不解释变量、单位和变化方向。
- 多变量梯度的分量顺序与参数顺序不一致。
- 使用链式法则时漏掉内层导数。
- 只用一个有限差分步长，误把巧合接近当成正确。
- 认为沿负梯度走任意大一步都会下降。

## 8. Worked Example：检查灰度增益损失的梯度

设一个像素原始灰度为 $p=80$，希望经简化增益 $g$ 后接近目标 $t=100$。定义平方损失：

$$
L(g)=(gp-t)^2.
$$

令 $q(g)=gp-t$，由链式法则：

$$
\frac{dL}{dg}=2q(g)\frac{dq}{dg}=2(gp-t)p.
$$

在 $g=1$ 时，$gp-t=-20$，所以梯度为 $-3200$。负号表示在足够小的局部范围内增大 $g$ 会减小损失。

```python
def loss(gain, pixel=80.0, target=100.0):
    error = gain * pixel - target
    return error * error


def analytic_gradient(gain, pixel=80.0, target=100.0):
    return 2.0 * (gain * pixel - target) * pixel


def central_difference(function, x, step):
    return (function(x + step) - function(x - step)) / (2.0 * step)


gain = 1.0
for step in (1e-2, 1e-4, 1e-6, 1e-8):
    numerical = central_difference(loss, gain, step)
    analytical = analytic_gradient(gain)
    print(step, analytical, numerical, abs(analytical - numerical))
```

这个例子只验证复合函数和梯度检查，不是完整的相机曝光模型。真实曝光还受响应曲线、饱和、噪声和照明影响。

## 10. Practice 练习

### 理解检查

对 $L(x)=(x-3)^2$ 写出导数，并判断 $x=0,3,5$ 处负梯度指向哪边。完成标准：方向判断与直接比较相邻函数值一致。

### 简单应用

对 $L(x,y)=(x-3)^2+2(y-1)^2$ 推导梯度，在 `(0, 0)` 手算结果。完成标准：两分量顺序明确，并用二维中心差分在 `1e-4` 步长下得到相对误差小于 `1e-6` 的核对。

### 视觉小练习

取一行灰度 `[20, 24, 35, 80, 132, 140]`，用中心差分估计内部位置的空间梯度，指出变化最强的位置。完成标准：列出每个内部位置的计算，并说明边界像素为何需要另定规则。
