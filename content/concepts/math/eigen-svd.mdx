# 特征方向、奇异值分解与低秩信息（Eigen Directions, Singular Value Decomposition, and Low-Rank Information）

本单元的目标是“看懂和会用”：理解矩阵怎样暴露主要方向与信息量，用小型数值实验检查 rank 和低秩近似，而不是完成一门特征分解理论课。

## 1. 这是什么

对方阵 $A$，若一个非零方向 $v$ 经过变换后仍沿同一条方向轴，只改变尺度或翻转方向，即

$$
Av=\lambda v,
$$

则 $v$ 是**特征向量（eigenvector）**，$\lambda$ 是对应的**特征值（eigenvalue）**。它回答“哪些方向经过这个变换后不拐弯，只缩放”。

**奇异值分解（Singular Value Decomposition, SVD）**适用于任意 $m\times n$ 实矩阵：

$$
A=U\Sigma V^T.
$$

可以按从右到左理解：$V^T$ 把输入改写到一组重要方向，$\Sigma$ 沿这些方向分别缩放，$U$ 把缩放后的方向放到输出空间。非负的**奇异值（singular values）**按大小描述各方向被保留或放大的程度。

两者不是同一种分解：eigen decomposition 主要询问方阵作用在自身空间时，哪些方向不会拐弯；SVD 则把一般 $m\times n$ 矩阵拆成输入方向、缩放和输出方向，即使输入与输出维数不同也可以使用。

## 2. 为什么机器视觉需要它

### 为什么现在学

Stage 1A 已经学习线性变换和秩，least squares 又让 `rank` 与 `singular_values` 出现在求解器输出中。现在需要建立解释这些值的能力：哪条方向最重要、哪些方向几乎没有信息，以及丢弃小奇异值会损失什么。

### 在机器视觉中会在哪里使用

- 二维点集的 PCA 主要方向与形状概括；
- 图像矩阵的低秩近似和压缩直觉；
- `geometry.epipolar` 等几何估计中的秩约束；
- 标定、重建与点云处理中识别主要方向或退化配置；
- least squares 求解器中的 rank 与奇异值诊断。

## 3. 前置知识

硬前置是 `math.linear-transforms`：需要能从基向量去向理解矩阵，并解释 rank 下降意味着信息丢失。`math.least-squares` 是 recommended：它提供 rank 与残差背景，但本页可先从二维点集开始。

代码使用 `numpy.linalg.svd`，只局部说明输入与返回 shape；不把尚未正式发布的 NumPy Concept 伪造成 dependency。

## 4. 核心概念

- **特征方向**：$Av=\lambda v$ 只针对方阵。$v$ 的长度任意，通常归一化；$v$ 与 $-v$ 表示同一条方向轴。
- **特征值的尺度含义**：$|\lambda|$ 表示沿该方向的缩放强弱，负号还表示方向翻转。不是所有矩阵都能用一组实特征向量完整表达。
- **SVD 的三个动作**：$V^T$ 选择输入方向，$\Sigma$ 缩放，$U$ 给出单位化的输出侧方向。对数据矩阵，带尺度的样本 scores / 坐标是 $U\Sigma$，不是单独的 $U$。
- **NumPy 返回的是向量 `s`**：`numpy.linalg.svd` 返回 `U, s, Vh`，其中 `Vh` 就是 $V^T$，`s` 是按从大到小排列的一维奇异值向量，不是矩阵 $\Sigma$。需要矩阵形式时再构造 $\Sigma=\operatorname{diag}(s)$。
- **奇异值与 rank**：非零奇异值的数量等于矩阵的 rank。实际浮点数据很少恰好为零，因此“有效 rank”需要结合尺度和任务容差判断；完整数值稳定性留到 `math.numerical-stability`。
- **主要方向**：较大奇异值对应数据变化更强或矩阵保留更多能量的方向；小奇异值对应较弱方向。大不自动等于有用，仍要结合单位和任务。
- **低秩近似**：只保留前 $k$ 个奇异值得到 $A_k=U_k\Sigma_kV_k^T$。它保留主要结构并丢弃较弱方向，重建误差说明代价。
- **二维 PCA 联系**：将点集每列减去均值得到中心化矩阵 $X$。对 $X$ 做 SVD 时，$V^T$ 的第一行给出最大变化方向；$s_i^2/(n-1)$ 对应沿该方向的样本方差。当前只需会解释，不证明该关系。

### Reduced SVD 的 shape

令输入 $A$ 的 shape 为 $m\times n$，并令 $k=\min(m,n)$。当 NumPy 使用 `full_matrices=False` 时：

| 对象 | shape | 当前应怎样读 |
|---|---:|---|
| 输入 $A$ | $m\times n$ | $m$ 个输出侧分量与 $n$ 个输入侧分量之间的线性关系 |
| reduced $U$ | $m\times k$ | $k$ 条单位化输出侧方向 |
| `s` | 长度 $k$ | 一维奇异值向量，不是矩阵 |
| $\Sigma=\operatorname{diag}(s)$ | $k\times k$ | 把每条方向按对应奇异值缩放 |
| `Vh` $=V^T$ | $k\times n$ | $k$ 条输入侧方向按行排列 |

数学上 $A=U\Sigma V^T$；在浮点代码中重建结果允许有微小误差，所以检查时写作 $A\approx U\Sigma V^T$。

## 5. 初学者直觉解释

把一团二维点想成一支倾斜的铅笔云。最长的方向是数据变化最大的方向，垂直方向可能只有少量厚度。SVD 像先转动坐标轴对齐铅笔，再读取“长度”和“厚度”，最后说明这些方向在原坐标中朝哪里。

| SVD 部分 | 初学者问题 | 二维点集中的含义 |
|---|---|---|
| $V^T$ | 输入中的重要方向朝哪里？ | 主轴方向 |
| $\Sigma$ | 每条方向有多强？ | 沿主轴的变化量 |
| $U$ | 输出侧的单位方向怎样排列？ | 样本侧的单位化模式，尚未带奇异值尺度 |
| $U\Sigma$ | 每个样本在各模式上的带尺度坐标是多少？ | PCA 中常说的样本 scores |
| 截断 | 丢掉弱方向后还剩什么？ | 细长点云可近似成一条线 |

## 7. 常见误区

- 把 eigen decomposition 与 SVD 当作完全相同的分解。
- 忘记 NumPy 返回的是 `Vh = V^T`，导致方向取错行列。
- 看到主方向符号相反就认为计算错误；$v$ 与 $-v$ 是同一条轴。
- 只报告奇异值，不写矩阵 shape、单位或对应方向。
- 把很小的浮点奇异值直接宣称为严格零。
- 低秩重建看起来不错就不报告误差和丢失信息。

## 8. Worked Example：二维点集的主方向与 rank-1 重建

四个已经中心化的二维点都落在 $y=x$ 上：

$$
X=\begin{bmatrix}
-2&-2\\
-1&-1\\
1&1\\
2&2
\end{bmatrix}_{4\times2}.
$$

这里只有一条独立方向，所以 rank 为 1。SVD 的第一条输入方向约为 $[0.707,0.707]$ 或它的相反数，奇异值约为 $[4.472,0]$。第二个奇异值为零，说明垂直于 $y=x$ 的方向没有变化信息。

这里 $X$ 是 $4\times2$，所以 $m=4,n=2,k=2$。使用 reduced SVD 后，`U` 是 $4\times2$、`s` 长度为 2、`Vh` 是 $2\times2$，由 `s` 构造的 $\Sigma$ 是 $2\times2$：

```text
X: 4×2 → U: 4×2 → s: 2 → Σ: 2×2 → Vh: 2×2
```

```python
import numpy as np

points = np.array(
    [
        [-2.0, -2.0],
        [-1.0, -1.0],
        [1.0, 1.0],
        [2.0, 2.0],
    ]
)

mean = points.mean(axis=0)
centered = points - mean
u, s, vh = np.linalg.svd(centered, full_matrices=False)
sigma = np.diag(s)
reconstructed = u @ sigma @ vh

rank_one = (u[:, :1] * s[:1]) @ vh[:1, :]
rank_zero = np.zeros_like(centered)
full_error = np.linalg.norm(centered - reconstructed)
error_rank_one = np.linalg.norm(centered - rank_one)
error_rank_zero = np.linalg.norm(centered - rank_zero)

print("mean:", mean)
print("shapes:", u.shape, s.shape, sigma.shape, vh.shape)
print("singular values:", s)
print("first principal direction:", vh[0])
print("full reconstruction error:", full_error)
print("rank-1 error:", error_rank_one)
print("rank-0 error:", error_rank_zero)

assert centered.shape == (4, 2)
assert u.shape == (4, 2) and s.shape == (2,) and sigma.shape == (2, 2) and vh.shape == (2, 2)
assert full_error < 1e-12
assert error_rank_one < 1e-12
assert error_rank_zero > 4.0
```

`s` 只有两个数；`sigma = np.diag(s)` 才把它们放到 $2\times2$ 的 $\Sigma$ 对角线上。`u @ sigma` 是带尺度的样本 scores，再乘 `vh` 回到原来的二维特征坐标。保留第一奇异值即可完整重建这些理想点；全部丢弃则只剩中心点。若给点加入轻微垂直噪声，第二奇异值会变成小的非零数，rank-1 重建也会出现小误差。是否应丢弃它取决于任务容差，而不是看到“小”就自动删除。

作为最小 eigen 直觉，矩阵 $D=\operatorname{diag}(3,1)$ 对 $e_1$ 放大 3 倍、对 $e_2$ 保持不变，所以两根坐标轴就是特征方向，特征值分别为 3 和 1。当前无需解特征多项式。

## 10. Practice 练习

### 理解检查

对 $D=\begin{bmatrix}3&0\\0&1\end{bmatrix}$，分别计算 $De_1$、$De_2$ 和 $D[1,1]^T$。完成标准：指出哪些向量是特征方向、对应特征值是什么，并解释 `[1, 1]` 为什么不是特征方向。

### 简单应用

用 `numpy.linalg.svd(..., full_matrices=False)` 分解矩阵 `[[3, 0], [0, 1]]`，先由 `s` 构造 `Sigma = diag(s)`，再用 `U @ Sigma @ Vh` 重建。完成标准：写出 `U, s, Sigma, Vh` 的 shape，重建最大绝对误差小于 `1e-12`，并把两个奇异值同两个轴的缩放联系起来。

### 视觉小练习

在 Worked Example 的四个点上给第二列加入 `[0.2, -0.1, 0.1, -0.2]`，比较 rank-1 与 rank-2 重建。完成标准：报告中心化均值、两个奇异值、第一主方向、两种重建误差；用一句具体结论说明 rank-1 丢失的是哪类变化。允许主方向整体符号相反。
