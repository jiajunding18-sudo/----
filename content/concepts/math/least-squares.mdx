# 最小二乘、残差与超定方程（Least Squares, Residuals, and Overdetermined Systems）

本单元只学习视觉工程最常用的最小二乘闭环：从测量建立方程、求一个总体折中、检查残差，并识别普通最小二乘何时会被异常值误导。

## 1. 这是什么

若未知参数为 $x$，理想模型可以写成 $Ax=b$。现实测量含噪声、量化和建模误差，多条方程往往无法被同一个 $x$ 精确满足，所以更诚实的写法是 $Ax\approx b$。

预测与观测之差叫**残差（residual）**。本文约定

$$
r=b-Ax.
$$

普通**最小二乘（least squares）**寻找让残差平方和最小的参数：

$$
x^*=\arg\min_x\|b-Ax\|_2^2
=\arg\min_x\sum_{i=1}^{m}r_i^2.
$$

这行记号只是在压缩一句白话：**`arg min` 返回让目标最小的参数 $x$，不是最小目标值本身**；$\|r\|_2^2$ 表示把残差向量每一项平方后相加；求和符号 $\sum$（读作 Sigma，形状来自大写希腊字母 $\Sigma$）表示“把指定范围内的项依次相加”，这里就是 $r_1^2+r_2^2+\cdots+r_m^2$。

当方程数 $m$ 大于未知参数数 $n$ 时，称为**超定系统（overdetermined system）**。这不是“方程太多”的错误；在视觉工程中，多次观测常用来约束少量参数并暴露不一致。

## 2. 为什么机器视觉需要它

### 为什么现在学

Stage 1A 已经提供矩阵 shape 和噪声/抽样语言。现在可以把“多次测量不完全一致”转化为一个可计算、可检查的参数估计问题。后续调用标定或几何估计 API 时，核心问题不只是能否返回参数，而是残差是否支持该结果。

### 在机器视觉中会在哪里使用

- 从多次测量拟合直线、平面或简单响应关系；
- `geometry.homography` 与 `camera.calibration` 中由多组对应建立参数；
- `robust.ransac` 中比较普通拟合与离群点抵抗；
- `pointcloud.icp` 中反复减小配准残差；
- 光流和局部几何估计中的小型超定方程。

## 3. 前置知识

硬前置是 `math.vectors-matrices`：开始前应能解释 $A_{m\times n}x_{n\times1}$ 的结果 shape，并给每列参数写出语义。`math.probability-statistics` 是 recommended：它帮助解释噪声、异常值和残差波动，但不要求先完成统计推断。

代码使用 `numpy.linalg.lstsq` 作为一个局部工具。尚未发布的 `python.numpy-arrays` 不会被伪造成 dependency；示例会把数组 shape 和返回值逐项写清，纸面模型仍是核心。

## 4. 核心概念

- **模型与数据分开**：$A$ 描述每次观测怎样依赖参数，$b$ 保存实际测量，$x$ 是待估参数。
- **超定不等于矛盾**：若 $m>n$，多条近似约束共同估计少量参数；带噪后通常没有精确交点。
- **预测与残差**：$\hat b=Ax^*$ 是模型预测，$r=b-\hat b$ 是每条观测没有被解释的部分。必须声明符号约定。
- **平方残差目标**：平方让正负残差都增加代价，并使大残差受到更强惩罚。它不自动证明噪声模型正确。
- **满列秩的最低限度直觉**：$A$ 的每一列对应一个参数。若 `lstsq` 返回的 `rank` 等于参数数目 $n$，称为满列秩，表示这些列提供了足够独立的约束，可以把不同参数的作用区分开；若 `rank<n`，某些参数组合无法由当前数据单独确定。本页只记录并比较 `rank` 与 $n$，不研究算法怎样从奇异值判断 rank。
- **参数解不等于可信结论**：总残差小可能因为单位、尺度或数据范围有限；还要逐项看残差、图形和异常点。
- **异常值敏感性**：平方会放大大残差，因此普通最小二乘容易被少数异常点拉动。鲁棒估计将在后续 `robust.ransac` 正式学习。
- **工程求解**：使用 `lstsq` 直接求解，不通过显式形成 $(A^TA)^{-1}$。当前不推导正规方程，也不学习 QR/SVD 的内部算法。

## 5. 初学者直觉解释

想象四把尺子都在估计同一条直线，但读数有一点偏差。没有哪条直线能穿过全部点，最小二乘会寻找一个总体上“离这些点不太远”的折中。

残差不是算法失败提示，而是结果的一部分：

| 对象 | 问题 |
|---|---|
| 参数 $x^*$ | 最终选择了什么模型？ |
| 预测 $Ax^*$ | 该模型认为每次观测应是多少？ |
| 残差 $b-Ax^*$ | 每次观测还有多少没有解释？ |
| 残差图/表 | 错误是随机散布、系统偏差还是单个异常？ |

## 6. 必须掌握到什么程度

- **知道是什么**：能说明 residual、least squares 和 overdetermined system。
- **理解**：能解释为什么现实测量没有精确公共解，以及平方残差为何对异常值敏感。
- **应用**：能从简单拟合建立 $A,x,b$，用 `lstsq` 求解并检查逐项残差与总平方残差。
- **达到本页 `master` 目标**：必须提交完整建模、求解、残差解释和异常值对照，覆盖两项 mastery criterion。

当前不要求推导正规方程，不要求证明伪逆，不要求学习 QR、SVD 的数值求解细节，也不要求进入回归推断、置信区间或假设检验。

## 7. 常见误区

- 只报告斜率和截距，不报告数据、单位或残差。
- 把 residual、测量噪声和真实参数误差当作同一个量。
- 看到 $m>n$ 就认为方程无解，而不区分精确解和近似解。
- 直接计算矩阵逆，把“公式能写”误当作稳定实现。
- 用总残差掩盖一个明显异常点或系统性弯曲。
- 把拟合线画得顺眼当作完成标准。

## 8. Worked Example：四次带噪测量拟合直线

把一组图像中的横向像素坐标记为 $u=[0,1,2,3]$ pixel，对应边缘的纵向测量记为 $v=[1.1,2.0,2.9,4.2]$ pixel，拟合

$$
v\approx mu+c.
$$

令参数 $x=[m,c]^T$，则

$$
A=\begin{bmatrix}
0&1\\1&1\\2&1\\3&1
\end{bmatrix}_{4\times2},\quad
x=\begin{bmatrix}m\\c\end{bmatrix}_{2\times1},\quad
b=\begin{bmatrix}1.1\\2.0\\2.9\\4.2\end{bmatrix}_{4\times1}.
$$

这是 4 条方程估计 2 个参数的超定系统。最小二乘结果为 $m=1.02,c=1.02$。预测是 `[1.02, 2.04, 3.06, 4.08]`，按 $r=b-Ax$ 得到残差 `[0.08, -0.04, -0.16, 0.12]`，平方残差和为 $0.048$。

单位也属于模型：$u$ 与 $v$ 都用 pixel，因此斜率 $m$ 的单位是 `pixel/pixel`（数值上常视为无量纲），截距 $c$、prediction 与 residual 都是 pixel，平方残差和的单位是 `pixel²`。如果 $u$ 改用毫米而 $v$ 仍用像素，斜率单位就会变成 `pixel/mm`，不能只看数值不写单位。

```python
import numpy as np

positions = np.array([0.0, 1.0, 2.0, 3.0])
measurements = np.array([1.1, 2.0, 2.9, 4.2])

# 每行是一条观测；两列分别乘斜率 m 与截距 c。
design = np.column_stack((positions, np.ones_like(positions)))
parameters, returned_residuals, rank, _singular_values = np.linalg.lstsq(
    design,
    measurements,
    rcond=None,
)

predictions = design @ parameters
residuals = measurements - predictions
squared_residual_sum = residuals @ residuals

print("A shape:", design.shape)
print("m, c:", parameters)
print("residuals:", residuals)
print("sum of squared residuals:", squared_residual_sum)
print("reported by lstsq:", returned_residuals)
print("rank:", rank, "parameter count:", design.shape[1])

assert design.shape == (4, 2)
assert rank == design.shape[1]
assert abs(squared_residual_sum - 0.048) < 1e-12
```

这里 `rank == 2`，与两列参数相同，因此当前数据对斜率和截距提供了两个独立约束。`lstsq` 还会返回 singular values，但本页不要求解释；奇异值、有效 rank 与容差的深入含义在 `math.eigen-svd` 学习。不要因为 API 返回了这些值就提前把 SVD 当作已掌握。

若把最后一个测量从 `4.2` 改成 `8.0`，新直线会明显被拉向异常点。这个对照说明普通最小二乘提供的是平方残差意义下的折中，不是自动可靠的真实模型。

## 10. Practice 练习

### 理解检查

三个测量方程估计一个未知长度：$x\approx10.0$、$x\approx10.2$、$x\approx9.8$。写出 $A,x,b$ 的 shape，并说明为何没有必要丢掉其中两条。完成标准：$A$ 为 `3×1`，并能用残差说明三条信息如何共同约束参数。

### 简单应用

手算常数模型对 `[10.0, 10.2, 9.8]` 的最小二乘估计、三个残差和平方残差和，再用 `lstsq` 核对。完成标准：估计为 `10.0`，残差和接近 0，手算与代码误差小于 `1e-12`。

### 视觉小练习

复现 Worked Example，再把最后一个测量改成 `8.0`。完成标准：提交前后两组参数、逐点 residual 和平方残差和；比较加入异常值前后的参数移动与每一项 residual 变化，并用具体数值解释普通最小二乘为何不再代表大多数测量。无需学习 leverage / influence，也无需实现 RANSAC。
