# 向量、矩阵与基本运算（Vectors, Matrices, and Basic Operations）

本单元不是完整线性代数课。目标是让你看到视觉公式或数组时，先问清楚“每个数表示什么、形状是什么、这个乘法合法吗”。

## 1. 这是什么

**向量（vector）**是一组有顺序的数，可以表示一个像素的 RGB 颜色、一个二维坐标或一组测量值。**矩阵（matrix）**按行和列组织数，可以表示一批像素、多个点或一个线性变换。

向量和矩阵不是只有数值：它们还带有**形状（shape）**和语义。例如一个 RGB 像素可以记为长度 3 的向量，一批 $N$ 个 RGB 像素可以记为 $N\times3$ 的矩阵。

## 2. 为什么机器视觉需要它

### 为什么现在学

Stage 2 会把图像当作数组处理。若现在不能解释行、列、通道和矩阵乘法的形状，后面即使代码运行，也可能把宽高、RGB 顺序或点的排列方式弄错。Stage 0 的 Python 已足以做小规模手算和最小代码检查；NumPy 数组是后续 Stage 2 的推荐伴随知识，不是本页的伪造前置。

### 在机器视觉中会在哪里使用

- 图像数组、颜色转换和批量像素运算；
- 卷积中小窗口与权重的乘加；
- 像素点、相机参数、位姿和点云的形状表达；
- 标定、重建与训练中对维度和数值结果的第一层检查。

## 3. 前置知识

硬前置是 `tooling.python-core`：你需要能使用列表、循环、函数和断言。暂时不要求已经掌握 NumPy；正文用手算和普通 Python 建立数学含义，后续发布 `python.numpy-arrays` 后再把相同检查迁移到数组代码。

## 4. 核心概念

- **形状**：矩阵 $A\in\mathbb{R}^{m\times n}$ 有 $m$ 行、$n$ 列。写形状时同时写语义，例如“3 个像素 × 3 个颜色通道”。
- **加法与数乘**：只有形状相同的向量或矩阵才能逐项相加；数乘改变大小，不改变形状。
- **点积（dot product）**：两个等长向量对应元素相乘后求和，结果是标量。它常表示加权和或相似程度，但具体意义取决于数据是否已归一化。
- **矩阵乘法（matrix multiplication）**：$A_{m\times n}B_{n\times p}=C_{m\times p}$。中间维必须相同，外侧维决定结果形状。
- **转置（transpose）**：$A^T$ 交换行列。转置不是“让报错消失”的工具；它会改变数据组织方式，必须解释新行列的含义。
- **单位矩阵与逆（identity and inverse）**：$I$ 保持向量不变；若方阵 $A$ 可逆，则 $A^{-1}A=I$。工程代码通常优先求解线性方程，而不是显式计算逆；数值稳定性将在 Stage 1B 深入。

## 5. 初学者直觉解释

把形状想成插头规格。矩阵乘法要求前一个对象的“输出接口”与后一个对象的“输入接口”一致。两个维度恰好都是 3，不代表语义一定相同：三个颜色通道和三个位姿参数都写成长度 3，但不能因此随意相加。

## 6. 必须掌握到什么程度

- **知道是什么**：能认出标量、向量、矩阵、行、列和 shape。
- **理解**：能在纸上解释点积、矩阵乘法、转置和逆分别改变什么。
- **应用**：面对颜色向量或点集，能先写形状再手算，并用最小程序核对。
- **达到本页 `master` 目标**：必须独立完成形状表、合法性判断、数值计算和失败诊断，并提交 frontmatter 中两项 mastery criterion 的通过证据。

当前不要求证明所有矩阵定理，不要求学习抽象向量空间，也不要求推导通用矩阵分解。特征值、SVD、最小二乘和条件数属于 Stage 1B。

## 7. 常见误区

- 只看元素总数，不写行列含义。
- 把逐元素乘法和矩阵乘法当成同一件事。
- 为了通过 shape 检查随意转置，却无法解释新维度。
- 认为任意方阵都有逆，或把显式求逆当作求解方程的默认方法。
- 代码输出一个数字就相信结果，不核对颜色顺序、单位和数量级。

## 8. Worked Example：一批 RGB 像素的灰度加权

三个 RGB 像素按“每行一个像素”组织：

$$
P=
\begin{bmatrix}
100 & 150 & 200\\
20 & 40 & 60\\
255 & 255 & 255
\end{bmatrix}
\quad (3\text{ 个像素}\times3\text{ 个通道})
$$

取一组用于演示线性加权的系数 $w=[0.299,0.587,0.114]^T$，形状为 $3\times1$。因此 $Pw$ 合法，结果形状为 $3\times1$。第一行手算为：

$$
100\times0.299+150\times0.587+200\times0.114=140.75
$$

下面先用 Stage 0 已有的 Python 能力核对，不把 NumPy 当作已学前置：

```python
pixels = [
    [100, 150, 200],
    [20, 40, 60],
    [255, 255, 255],
]
weights = [0.299, 0.587, 0.114]


def dot(left, right):
    if len(left) != len(right):
        raise ValueError(f"长度不匹配：{len(left)} != {len(right)}")
    return sum(a * b for a, b in zip(left, right, strict=True))


gray_values = [dot(pixel, weights) for pixel in pixels]
print(gray_values)
```

这里验证的是形状与加权和，不是要求你背诵某个颜色标准。真实图像库还涉及颜色空间、通道顺序、量化与舍入，必须查看对应 API 的约定。

## 10. Practice 练习

### 理解检查

为 $A_{2\times3}$、$x_{3\times1}$、$B_{3\times4}$ 列出所有合法的两两乘法，并写出结果形状。完成标准：每个判断都写出中间维，而不是只写答案。

### 简单应用

手算两个 RGB 像素的加权结果，再修改 `dot` 的输入使其触发长度错误。完成标准：手算与程序误差小于 `1e-9`，错误信息包含两个长度。

### 视觉小练习

把四个二维点组织成“4 个点 × 2 个坐标”的矩阵，设计一个 $2\times2$ 矩阵并预测乘法后的结果形状。完成标准：逐行解释每个点的变化，并指出采用的是行向量还是列向量约定。
